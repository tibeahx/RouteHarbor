# Changelog

## Unreleased — development preview

- RouteHarbor identity across the repository, CLI, packages, services, state paths
  and English offline control panel, with original light/dark README wordmarks and
  a matching application icon. Earlier installations require the documented
  [identity transition](docs/branding.md#installation-identity).
- Versioned private configuration, source adapters, independent HTTPS probes and
  freshness-aware channel selection with degradation/recovery tests.
- Authenticated public API, revocable admin/read credentials, revision conflicts,
  bounded durable operations, diagnostics and explicit private export/age backup.
- Owned nftables/routes, typed Unix helper, independent rollback and real Linux labs.
- Node certificate pairing, capabilities, scoped UCI transactions and own watchdog.
- Coordinated gateway/node Wi-Fi setup with private credential transfer, verified
  pair receipts, independent rollback and confirmation recovery.
- Bounded speed checks on suspected degradation and an optional, default-off reset
  of the previous source's connection tracking, with durable failure reporting.
- OpenWrt package definitions, cross-build tooling, signed release verification and
  operational/development/security guides.
- Go 1.27.1, golangci-lint 2.13.2, built-in Go formatters and Prettier 3.9.6 with
  local scripts and CI checks. Real SDK packages and isolated OpenWrt userland
  installation/service/firewall/removal checks.

No stable router release or physical compatibility certification is declared.
