# Архитектура OpenRHP

OpenRHP расшифровывается как **OpenReverseHomeProxy**. Контроллер написан на Go;
пакеты пользователей пересылают ядро Linux и отдельные сетевые движки.

`internal/model` — публичные структуры схемы 1. `config` проверяет и атомарно
сохраняет пользовательские данные. `selection` принимает решения только по свежим
измерениям отдельного источника. `adapter` создаёт независимые пути, `probe`
проверяет ресурсы. `platform` обнаруживает возможности. `dataplane` генерирует
только собственные сетевые объекты. Привилегированный helper повторно проверяет
типизированные запросы; HTTP-сервис не выполняет произвольные команды.

API `/api/v1` — общий интерфейс панели и агентов. Любая настройка сети проходит
prepare → validate → apply → confirm с локальным журналом и независимым откатом.
Автоматическое переключение меняет путь новых соединений. Сохранение TCP-сессий
при смене внешнего IP не обещается. Неизвестная метрика отсутствует, а не равна нулю.

Первичная установка оставляет обработку трафика выключенной. Неподдерживаемые
ядро, firewall, IPv6, DNS или изоляция движка останавливают применение до изменения
сети. Fail-closed не должен откатываться в незапрошенный прямой выход.

Контракт API фиксируется в `api/openapi.yaml` до реализации панели. Возможности
сборки, виртуального стенда и физического устройства учитываются раздельно.
