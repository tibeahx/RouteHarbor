# Applicable security controls and evidence

This matrix maps the implemented control areas to [OWASP ASVS 5.0.0](https://owasp.org/www-project-application-security-verification-standard/) and the [OWASP API Security Top 10, 2023 edition](https://owasp.org/API-Security/editions/2023/en/0x11-t10/). It is an implementation checklist with named evidence, not a complete ASVS assessment, certification, or guarantee. Exact requirement IDs are used only where the corresponding versioned requirement was checked.

| Control area | Application to RouteHarbor | Evidence and remaining boundary |
| --- | --- | --- |
| ASVS v5.0.0-1.2.5, OS command injection | Fixed executables, validated typed arguments, strict source subsets, no imported scripts; UCI secret assignments use parser-specific stdin quoting. | [Adapter import tests](../internal/adapter/validate_test.go), [helper decoder tests](../internal/helper/manager_test.go), [actual UCI parser test](../internal/node/uci_parser_test.go). A full engine configuration is intentionally rejected. |
| ASVS browser encoding; API8 security configuration | Untrusted text uses DOM text nodes; CSP and Host/Origin checks; no browser credential persistence or external scripts. | [Real browser tests](../tests/browser/control.spec.js), [API security tests](../internal/api/server_test.go). Browser extensions and an already compromised administrator device are outside this boundary. |
| ASVS authentication/session controls; API2 authentication | Random scoped bearer credentials, local trusted bootstrap, hashed credential persistence, authoritative revocation and bounded enrollment challenges. | [Authentication tests](../internal/auth/auth_test.go), [node TLS tests](../internal/node/node_test.go). The first LAN visitor never acquires ownership. |
| ASVS authorization; API1/API3/API5 authorization | Every API route authenticates; writes and secret export need admin; read-only tokens cannot invoke privileged mutations. Ordinary output uses allowlists. | [API ACL and secret tests](../internal/api/server_test.go). The current household model grants admin access to all owned sources/nodes; it does not claim per-object delegated tenant roles. |
| ASVS input validation; API7 SSRF | Strict bounded JSON, numeric public-address checks, DNS result validation, pinned transport destinations, redirect checks, and separate explicit proxy endpoint permissions. | [Probe tests](../internal/probe/probe_test.go), [DNS path tests](../internal/probe/dns_test.go), [public address tests](../internal/platform/public_test.go). Controller DNS bootstrap disclosure is documented in the adapter guide. |
| API4 resource consumption | Request/body/output bounds, bounded operation journal, rate limits, capped probe concurrency/history, SSE quotas/deadlines, process timeouts. | [API tests](../internal/api/server_test.go), [configuration tests](../internal/config/config_test.go), [operation tests](../internal/control/operations_test.go). Sustained hardware load and flash endurance remain device acceptance work. |
| API6 sensitive workflow abuse | Revision comparisons, credential-scoped idempotency, serialized network changes, explicit prepare/apply/confirm and local rollback deadline. | [Coordinator tests](../internal/control/network_test.go), [helper transaction tests](../internal/helper/manager_test.go). Client connectivity must be checked before confirmation. |
| API9 inventory management | Embedded OpenAPI and registered routes must match in both directions; unsupported capabilities report a failure. | [Contract test](../internal/api/contract_test.go). Package/device support is listed separately from compilation results. |
| API10 unsafe upstream consumption | Pinned engine validators, strict imported settings, no downloaded shell, independently trusted signed release manifests, exact size/hash/architecture checks. | [Native engine tests](../internal/adapter/engine_integration_test.go), [release verifier tests](../internal/release/manifest_test.go). No production signing trust root or stable release is issued yet. |
| ASVS data protection and transport | Private local state, redacted ordinary exports, age-encrypted portable backup, TLS for non-loopback management, pinned node mutual TLS. | [Persistence tests](../internal/config/config_test.go), [node tests](../internal/node/node_test.go), [backup and trust guide](updates.md). Physical device compromise and operator recovery-key custody remain operational responsibilities. |
| Privileged boundary and failure recovery | Typed peer-authenticated helper, owned routing objects, independent rollback and process supervision; no automatic direct reopening. | [Real Linux laboratory](../scripts/lab-network.sh), [security review](security-review.md). Physical boot/WAN/DNS/IPv6 leak captures remain release gates. |

The [verification ledger](verification.md) is authoritative for executed checks and environment limits. The [independent implementation review](security-review.md) records reproduced defects and their corrections; passing a scanner does not replace that review.
